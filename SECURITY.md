# Security

ClipCraft is preview software. The latest published preview is the active maintenance
target; there is no security-support SLA or guarantee of vulnerability-free behavior.

Use this repository's **Security → Report a vulnerability** private reporting form.
Include the version, minimal synthetic reproduction and impact. Do not attach
personal captures, secrets or exploit details to a public issue. If private
reporting is unavailable, open an issue asking for a private contact without
disclosing the vulnerability.

Release checks include tests, dependency advisory checks and source publication
checks. Review actual workflow results and advisory findings. An SBOM and
provenance attestation identify contents and build origin; they do not certify
that an artifact is safe. See [security-model.md](docs/security-model.md).
