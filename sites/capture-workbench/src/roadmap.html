How to read the roadmap.

Planned means the feature is missing. In progress means implementation has begun. Needs verification means code exists but its completion checks are still pending.

Shipped requires evidence and a published release. Deferred includes a reason. Overdue preserves the original missed version target. Unscheduled means no new version is promised; priorities describe order. Active targets remain provisional.

The backlog is reviewed after each development pass and published when it changes. The changelog records releases; this page tracks the work still ahead.
